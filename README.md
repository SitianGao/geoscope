## 启动

双击 `启动Demo.bat`，在浏览器打开 http://127.0.0.1:4180 。需要Python与Pillow；当前电脑已具备。

其他电脑可在安装Python后运行 `python -m pip install -r requirements.txt`，再运行 `python server.py`。

网页仅由本机127.0.0.1提供，不需要构建或外部CDN。第一次启动无需模型权重。

## 推荐演示流程

1. 默认加载“街区建筑研究样区”，点击“先了解这幅影像”。
2. 点击或输入“提取右侧建筑并计算面积占比”。
3. 切换叠加、蒙版和对比视图，调整透明度，查看像素统计。
4. 继续输入“改成左侧的”，观察上下文继承和新版本。
5. 点击旧版本可以恢复显示，并基于该版本继续分析。
6. 输入“把那个区域提出来”，体验澄清；选定明确条件后执行。
7. 导出实验包，检查其中的六个文件。
8. 在顶部运行方式中使用“体验工具失败反馈”，观察失败状态与旧结果保留。

## 已实现与未实现

已实现：真实影像上传、规则驱动的演示任务路由、上下文继承、同一影像的结果版本、半幅像素范围筛选、根据二值蒙版计算面积与占比、可视化、ZIP导出、实际事件日志，以及明确的失败/澄清状态。

**RemoteAgent 与 RemoteSAM 权重已经分别部署和验证，但演示模式仍读取预置的近似人工多边形。** 演示模式不是模型预测，更不是评测真值；场景说明也是预置文本。真实模式只有在两个服务同时在线并明确配置后才调用模型。统计值由实际蒙版逐像素计算，而非固定界面数字。演示耗时不能当作模型推理速度。

真实模式的接入是一个受限工具集适配器：多模态认知核心返回结构化动作，Harness校验后调用RemoteSAM服务，生成结构化产物及确定性回复。它不等于原始RemoteAgent权重、训练流程或论文指标的完整复现，也未验证复杂推理与多轮自主重规划。此次交付目标为可审阅和可交互的系统初稿。

未提供：人工像素编辑、地理面积、精确实例计数、复杂空间关系、多时相分析。任意上传影像没有演示标注，不会被启发式伪分割；需要连接真实服务。若工具返回空蒙版，仅表示未检出，不断言现实不存在目标。

## 接入真实模型服务

将 `.env.example` 复制为根目录 `.env`，填写真实服务配置后启动，网页中点击“演示模式”切换。启动时自动加载 `.env`；已设置的进程环境变量优先。不要把密钥写入前端或提交到仓库。

| 变量 | 含义 |
|---|---|
| GEO_AGENT_BASE_URL | 多模态聊天兼容服务的API根地址，例如 http://127.0.0.1:8000/v1 |
| GEO_AGENT_MODEL | 服务实际模型名称；如使用替代模型须注明，不能冒充官方RemoteAgent |
| GEO_AGENT_API_KEY | 服务密钥；本地无需鉴权时可省略 |
| GEO_REMOTESAM_URL | RemoteSAM推理端点，例如 http://127.0.0.1:6657/predict |
| GEO_REMOTESAM_REVISION | 实际权重/服务版本标识；未知时留空，禁用真实蒙版复用 |
| GEO_SERVICE_PROXY_MODE | 默认 direct，模型服务请求不使用下载代理；确需环境代理时设 environment |
| GEO_PORT | 工作台端口，默认4180 |

认知核心调用请求含真实图像base64和所选结果的目标/范围上下文，要求返回scene、segment、clarify或export。非法动作会被拒绝。真实模式会向配置的模型地址发送影像与任务。

RemoteSAM适配本地上游服务格式：请求为task=referring_seg、image=base64 PNG、text=英文类别提示；响应需包含status=success及mask=base64 PNG。蒙版尺寸必须与原图完全一致，不静默拉伸。当前先提取整图类别再按像素半幅裁切，因此这是明确的空间约束实现，不宣称复现论文的指代表达推理精度。

顶部配置状态不代表服务可用。可在“运行方式 → 检查服务连接”或运行 `python scripts/check_services.py` 查询模型列表和 RemoteSAM 就绪声明；检查不上传影像、不运行推理。模型模式采用 RemoteAgent 官方 `<answer>` / `T_call(...)` 协议：工作台只允许指代分割和语义分割，绑定当前影像，执行 RemoteSAM 后回传实际统计。模型的文字不能覆盖工作台计算值，也不能在反馈阶段继续自行调用工具。

## 结果与统计约定

- 影像原点为左上角，X向右、Y向下；上下左右不是地理方向。
- 左半幅为x < floor(width/2)，右半幅包含其余像素；上下同理。
- 所有比例的分母始终是整幅影像像素数。二值蒙版的非零像素就是目标面积。
- 半幅筛选是像素范围裁切，跨中线的建筑会被截取；不把它描述为完整实例选择。
- “检查通过”只涉及尺寸、范围、文件及计算，不等于语义正确或边界精准。
- ZIP包含 original.png、mask.png、overlay.png、result.json、statistics.json、run_log.json。模式、数据来源、影像SHA256、任务与版本关系一并记录。
- 文件保存在experiments目录。会话可从磁盘恢复；刷新网页恢复最近实验，历史列表支持重新打开其他实验。
- 完整蒙版独立保存，修改左右范围时可复用；复用需影像、目标、服务版本与文件哈希一致。版本未知的真实服务每次重新分割；复用来源写入运行记录。

## 核查

`python -m unittest discover -s tests -v` 当前运行 51 项检查，覆盖 RemoteAgent 决策、场景理解与像素任务分流、非目标区域取反、官方模型实际出现的 `<answer>T_call(...)</answer>` 与单调用 XML 风格、多个工具调用拒绝、工具白名单、当前影像绑定、RemoteSAM 两种分割合同、工具结果反馈、飞机提示口径、复杂范围拒绝、文字回答不得冒充分割、推理文本脱敏、上下文、半幅统计、失败不产出、版本隔离、磁盘恢复、蒙版复用、二值编码及 HTTP 导出一致性。HTTP 集成测试使用明确标注的模拟服务；真实模型证据另见两项服务的部署和联调报告。

提交的两套评测指标可在离线状态下复算：`python evaluation/recompute_integrated_metrics.py --write`。脚本从逐任务/逐图 CSV 核对 RemoteAgent 汇总、RemoteSAM 的 TP/FP/FN、IoU、Dice 和接口合同。

`tests/browser.cjs` 为开发用浏览器检查，依赖本机Codex配套Playwright（运行时路径可用PLAYWRIGHT_PATH覆盖）。它检查主任务、条件修改、版本、下载、澄清、故障及移动端页面，截图位于test-results。
