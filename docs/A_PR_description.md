## 问题与修复

在已合并的国赛版本中，用户输入“提取最下面的船”，Agent 提示要求整图类别分割，最终请求降级为 semantic_seg / ship，生成全图船舶。新增独立的单目标位置合同，把 the bottommost ship 原样传入 SAM；丢失位置或改成类别工具则停止执行。最上/最下/最左/最右不等于像素半幅，复杂位置、数量和 ROI 冲突先澄清。普通整图/半幅、缓存、反馈及看图问答保持回归覆盖。

旧错误版本保留原蒙版和指标，但在界面显示需重跑告警，禁止误确认为指代任务完成。新标题、版本、分析范围和后续操作按指代对象显示。

RemoteCLIP 弹窗重整桌面/手机布局：统一卡片与按钮，显示真实尺寸和三位相似度，把原始分数、ID、哈希及版本收入折叠追溯，返回数量匹配实际图库。API 原始分数不变，候选选图仍使用绑定 session。

热重启的端口释放检查增加 SO_REUSEADDR 和有限等待，仍拒绝接管其他监听进程。补充生命周期竞争条件和 TCP 连接后的重启测试。
