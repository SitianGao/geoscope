# GeoScope 国赛作品演示脚本

作品演示约 4 分钟，PPT 与演示合计控制在 6 分钟以内。按组委会附件用腾讯会议连续录制，团队成员全程开摄像头，开头报团队名。画面保留匿名参赛要求，使用最终确认的 PPT 与工作台。 [预选赛通知及附件](https://www.aicomp.cn/notice/notice-1/5866.html)

## 录制前检查

1. 通过团队已有的服务器访问通道打开 `/?workbench=national`，确认工作台和 RemoteCLIP 已就绪。
2. 打开「实验记录」，确认 P1529 会话 `2b2acb90b45d` 可访问。基准版本为 `1e9614581f1c`，AFR 版本为 `37cfda0a9fc3`。
3. 预先打开两个版本确认分歧层可读，检查目标版本的实验包下载和 A0–A5 实验表。在单独标签页备好 P1529 的半幅统计证据，可定位到 `plan.data.events` 中的 `region_statistics`。复核结束后返回工作台。 [服务器接管与固定会话](https://github.com/SitianGao/geoscope/blob/1d0a138bbe9355e98761d9f17fe49db7646748d6/docs/A_captain_handoff.md) · [P1529 逐步骤证据](https://github.com/SitianGao/geoscope/blob/1d0a138bbe9355e98761d9f17fe49db7646748d6/docs/evidence/server/full_chain_p1529.json)

## 四分钟操作和讲稿

| 时间 | 屏幕操作 | 讲稿 |
| --- | --- | --- |
| 0:00–0:25 | 停在国赛工作台，指向当前影像、版本栏和结果区 | GeoScope 把遥感影像检索、飞机分割、同图对照和科研统计放在同一工作台。每张蒙版和每份报告都对应一个结果版本。 |
| 0:25–1:05 | 点击「语义检索」，输入 `airport with airplanes`，展示候选排序，点「分析该影像」 | 现在使用 RemoteCLIP 检索已有影像。候选按图文相似度排序，点击即可打开对应影像。随后我会从实验记录打开已经完成服务器验收的 P1529。 |
| 1:05–2:10 | 在「实验记录」打开 P1529，选 AFR 版本。点击「版本对照」，基准选 `1e9614581f1c`，对照选 `37cfda0a9fc3`。展示滑杆和差异层，点击「核对后端差异」 | 左右使用同一影像坐标。两个版本分别来自真实整图推理和 AFR 自适应推理。差异层标出对照版本新增及减少的像素，浏览器与后端可以分别复算。 |
| 2:10–3:00 | 打开「质量诊断」，切换分歧叠加，点一个待复核区域定位。展开「查看智能体执行过程」 | 分歧层标出整图和局部预测存在差异的区域。这次 AFR 运行选择了六个局部区域，有六个待复核区域。这里可以定位到局部，也能回看该版本的实际工具步骤。 |
| 3:00–3:35 | 先看 AFR 全图版本的结果卡，再切到备好的半幅统计证据。回到工作台，导出 AFR 版本实验包 | 这个保存版本的范围是全图。已执行的半幅任务统计左侧目标像素，占整图约 10.07%，占左半幅约 20.15%。导出包包含同一 AFR 版本的蒙版、报告、日志和诊断附件，可按结果 ID 复查。 |
| 3:35–4:05 | 点击「算法实验」，展示 A3–A5 的样本数、配置及逐图证据 | 实验页列出基线和 AFR 的六组实测配置。这里的指标来自固定十张飞机历史诊断图，后续还要在开发验证集上确定参数，并用独立测试集验证。 |

## 预备用法

如果临场无法连接服务器，打开本地集成版，用内置样例演示选图、ROI 分割、版本对照、双占比和导出。随后展示 A3–A5 的真实实验表和服务器保存的 P1529 分歧图截图。讲稿标明当前分割使用预置样例、分歧图为已保存的真实服务器结果。 [本地样例对照](screenshots/national-demo-difference.png) · [实测截图目录](https://github.com/SitianGao/geoscope/tree/1d0a138bbe9355e98761d9f17fe49db7646748d6/docs/evidence/server)
