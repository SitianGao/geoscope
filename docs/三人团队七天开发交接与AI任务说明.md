## 一、先了解项目现状

### 1. 我们要解决什么问题

目标用户是遥感相关专业学生、研究生和需要开展影像预标注、目标提取的科研人员。他们需要围绕同一影像连续完成场景理解、目标提取、统计、条件修改、结果整理。目前这些步骤常需要在模型、脚本和文件之间手动切换。

本项目让用户用自然语言组织这些实验步骤，并保留可复查的结果与版本。首版主线是：

**上传影像 → 理解任务 → 调用分割工具 → 几何筛选与统计 → 条件修改 → 版本管理 → 导出实验包。**

角色关系：

- **RemoteAgent：**认知核心，理解影像和任务、决定直接回答还是调用工具。
- **RemoteSAM：**专业感知工具，根据影像和文本生成分割蒙版。
- **几何与统计工具：**执行确定性的范围筛选、像素面积和比例计算。
- **Harness：**管理上下文、工具执行、检查、错误、结果文件和版本的程序。
- **Web 工作台：**上传、对话、可视化、版本查看与导出。

不新增 DINO+SAM、RemoteReasoner、RemoteZero、RemoteShield 等方法；本周不安排重新训练或强化学习。

### 4. 已确认的接入问题

1. RemoteAgent 的 `remoteagent/core/inference.py` 通用入口目前向模型发送图片路径文字，没有发送实际影像。仓库 `remoteagent/eval_common.py` 中有发送影像的实现可参考。
2. `remoteagent/services/executor.py` 的 RemoteSAM 调用主要返回文字摘要，没有将返回的分割蒙版完整交给后续系统。队员 A 提供保留工具结果的适配，队长完成工作台资产接收。
3. 配套 `servers/RemoteSAM/remotesam.py` 传入 `mask_output_hw`，但本地配套 `tasks/code/model.py` 的相关函数没有这个参数，需要统一接口。
4. Demo 的真实模式目前要求认知模型返回自定义 JSON，不能直接视为与官方 RemoteAgent 的工具调用格式兼容。需要保留官方格式的解析，并做系统适配。
5. RemoteSAM 当前服务启用了 EPOC，会加载额外辅助权重。部署者需核实依赖和使用情况，记录实际配置，不能静默改变配置后声称与原实现完全一致。

这些是对当前本地代码的检查结论；如果队员更新了上游版本，应重新核对，不能机械修改已经修复的代码。

| 负责人 | 主要职责 | 交付边界 |
|---|---|---|

**正式系统由队长维护的 Harness 统一管理状态和执行。** A 可用独立脚本验证官方完整推理流程，但最终接入时必须明确由谁控制执行循环，避免模型端和工作台各自重复调用工具。

| 日期 | 共同里程碑 |
|---|---|

| 第 2 天 | A 完成真实看图推理及工具调用输出；B 完成真实分割；两人交服务说明与运行证据 |
| 第 3 天 | 工作台完成新影像上传 → 真实分割 → 统计 → 展示 → 导出 |
| 第 4 天 | 连续修改、必要澄清、失败处理、版本恢复联调 |

上午确定当天交付，晚上用接口、文件和日志验收。阻塞应及时报告具体错误、已尝试的办法、缺失资源及需要谁协助。第 2 天若仍不能独立推理，优先集中解决部署，暂停非必要界面工作。

## 六、共同接口和验收约定

以下为建议的首版合同，第一天由三人确认。它不是已经完成的服务实现。

| 交接位置 | 需要传递的信息 | 负责对接 |
|---|---|---|
| 工作台 → Agent | 实际影像、用户指令、当前条件、当前版本和必要历史 | 队长与 A |
| Agent → Harness | 直接回答、工具调用或需澄清的结果；工具名与参数；保留原始模型响应 | A 与队长 |
| Harness → RemoteSAM | 影像内容、任务类型、文本提示 | 队长与 B |
| RemoteSAM → Harness | 状态、真实蒙版、尺寸及必要错误信息 | B 与队长 |
| Harness → Agent | 工具执行状态、结果摘要、程序计算的数值 | 队长与 A |
| Harness → 页面与导出 | 结果文件、统计、版本、日志、数据来源 | 队长 |

队员 A 可以提供进程内模块或独立服务，第一天确定，避免两边自行假定接口。模型不能直接决定任意本地文件访问路径；由 Harness 将任务中的影像标识绑定到当前会话资产，并校验调用参数。

共同演示指令：

1. “描述这幅影像。”
2. “提取右半幅的建筑像素，并计算其占整幅影像的比例。”
3. “改成左半幅。”
4. “恢复右半幅的结果并导出。”
5. “提取那个区域。”——若没有充分指向，系统应请求补充条件。

共同边界：

- 左右按图像像素坐标定义，不直接解释为地理东西方向。
- 首版范围筛选是蒙版与半幅区域求交，会截断跨中线目标，不宣称完整实例选择。
- 比例分母为整幅影像像素数。没有可靠地理信息时只提供像素面积。
- 已有整图同类蒙版且推理条件未变化时，范围变化可以复用；改变影像、提示或模型配置后不能盲目复用。
- 检查尺寸、文件和统计通过，不等于分割语义与边界准确。
- 结果包应包含 original.png、mask.png、overlay.png、result.json、statistics.json、run_log.json，并记录实际模型来源和版本。
