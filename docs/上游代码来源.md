# 上游代码来源和本次整理范围

上游项目：

- RemoteAgent：https://github.com/1e12Leon/RemoteAgent
- RemoteSAM：https://github.com/1e12Leon/RemoteSAM

本次从队长已有的本地源码文件夹复制代码，没有重新下载上游，也没有修改算法。原始文件夹没有可用于确认提交号的 Git 元数据，因此不编造上游 commit ID。逐文件来源和 SHA-256 见 `upstream_manifest.json`。

纳入范围：

1. RemoteAgent 的 `remoteagent/` Python、Shell、文本文件及上游 README。
2. RemoteAgent 配套 `servers/RemoteSAM/` 下的 Python、Shell、文本和 Markdown 文件。

未纳入：其他模型服务、论文 PDF、模型权重、数据集、评测用 pickle/JAR 等二进制资源及上游宣传图片。原 README 可能含图片或其他服务链接，在这个精简快照中可能不可用；需要完整上游评测时应另行获取对应资源。此快照的目的是支持本项目推理接入开发，不宣称包含上游完整训练和评测环境。

原代码中的作者信息与出处保留。该来源说明不是重新授予许可证，也不改变上游代码的权利状态。本地顶层源码包未提供独立的 LICENSE 文件；需要对外再分发时应核实上游条款。

工作台的两张示例影像及人工演示蒙版来源见根目录 README。演示蒙版不是模型预测或评测真值。
