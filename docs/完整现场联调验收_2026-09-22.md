# GeoScope 完整现场联调验收

验收日期：2026-09-22

## 验收结论

官方 RemoteAgent、GeoScope Harness 与官方 RemoteSAM 已在同一真实任务中完成闭环：

```text
真实影像与中文请求
→ RemoteAgent 生成受限工具决策
→ Harness 校验并绑定当前影像
→ RemoteSAM 返回真实完整蒙版
→ Harness 校验尺寸、裁切右半幅并计算像素统计
→ 统计与产物摘要回填 RemoteAgent
→ 最终回答完成
```

这次验收没有使用 Demo 蒙版或固定答案。模型权重、令牌和原始 Base64 不进入 Git。

## 失败保护验证

第一次使用中文请求“提取右侧建筑并计算面积占比”时，模型同时给出了语义分割和未开放的区域轮廓工具。Harness 将响应判定为 `unparsed`，没有调用 RemoteSAM、没有生成蒙版，也没有产生伪统计。该结果验证了工具白名单和失败关闭行为。

随后强化运行时输出合同：提取任务只允许输出一次整图分割调用；左右、上下、面积和占比都由 Harness 处理；禁止调用轮廓或区域工具。官方模型随后按合同返回单一 `semantic_segmentation` 调用。

## 机场连续修改闭环

在机场样例的全图飞机真实结果上继续输入“改成左侧的飞机”。官方模型曾出现
`<T_call semantic_segmentation(...)></T_call>` 形式的单工具包装，旧解析器将其误判为
`unparsed`。解析兼容现只规范化一个工具调用；包含多个调用时仍失败关闭。

修复后同一会话现场结果如下：

上下文继承 → 完整蒙版安全复用 → 确定性空间裁切 → Agent结果回填”的交互链路。

## 通用看图问答与像素任务分流

用户上传 702×361 的普通树状图截图并询问“这张影像主要是什么场景？”时，旧版本错误进入多类别分割校验。修复后，同一图片、同一句话由 RemoteAgent 直接回答为两幅树状图，运行状态为 `answered`，没有调用 RemoteSAM。对应运行 ID 为 `125722bfeed5`，耗时 2576.19 ms。

工作台现将场景描述、看图问答、分类和计数归入 RemoteAgent 内部任务；“提取、分割、标注、圈出、蒙版、面积、占比”等请求归入像素任务。对“非飞机”等补集请求，RemoteAgent 只提取正类别，Harness 再对二值蒙版执行确定性取反。演示路径使用“把非飞机的部分标注出来”验证成功，页面能够显示“非飞机”版本并保留像素统计。

## 结论边界

本次验收证明代码、服务、工具编排、蒙版传输、确定性裁切、统计和结果回填能够真实运行。它只使用了一幅样例，不能作为语义精度、泛化能力或论文指标的证明。正式参赛前仍需使用来源明确的多幅遥感影像和人工标注，计算精度指标并保留失败案例。
