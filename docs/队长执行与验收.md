## 具体怎么运行检查

在工作台电脑、仓库根目录：

```text
python scripts/check_services.py
python scripts/check_agent_contract.py
python -m unittest discover -s tests -v
```

第二条检查 A 的代码是否可导入并具备 `plan` 与结果反馈接口；通过只代表接口完整。真实模型仍须启动 vLLM 后现场验证。

在已经登录的实验室机器，把 `scripts/lab_check.py` 放到自己的工作目录后：

```text
python3 lab_check.py --network --model-dir /实际权重目录
```

`--model-dir` 要填真实目录；还没有权重路径时省略该项。网络检查只访问模型信息和小配置文件，不下载大权重。默认和直连两种检测仅对该检查进程生效，不修改机器设置。报告会隐藏代理用户名和密码。
